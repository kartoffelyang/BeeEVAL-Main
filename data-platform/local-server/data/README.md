# Case classification snapshot

Display-only classification from the original BeeEVAL repository `api/data/test_case_tags.json`, retrieved 2026-10-20. This file retains only function domain, task type and acceptance grade by case ID. Evaluation records remain served by the authenticated original API; this snapshot grants no access to records and never changes the database.

Search uses explicit record classification first, then this official snapshot, and marks unknown cases unclassified. Refresh the snapshot when the source taxonomy changes. Basic/intermediate/advanced labels refer to the existing acceptance grades; they are not derived from model scores.
